# Trabalho2

**O programa ainda não está pronto!**
Mas caso queira testar mesmo assim, recomendo testar pelo software Dev-C++.

**COMO RODAR:**

1. Faça o download dos arquivos e os deixe numa página separada;
2. Abra o arquivo Trabalho2.dev (que deve abrir o Dev-C++ na hora);
3. Clique com o botão direito em cima do nome "Trabalho2.dev" e selecione a opção "Add to project";
4. Adicione os arquivos "main.c", "locadora.c" e "locadora.h" ao projeto;
5. Compile e execute (F11) o arquivo Trabalho2.c;
6. Pronto! você já está rodando o programa!
